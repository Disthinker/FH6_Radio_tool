# Release Notes - FH6 Radio Tool v2.6.2

## Release Type

Formal release package based on the v2.6.2 UI alignment build.

## Main Features

- Guided workflow instead of developer-style tabs.
- Show/hide setup panel.
- Show/hide right-side guide and runtime log panel.
- Resizable radio/music list area.
- Cleaner loop candidate and scene preview area.
- Fmod Bank Tools external automation with automatic working directory setup.
- Automatic backup and restore support.
- Chinese and English UI support.
- Game XML language selection.

## Package Cleanup

Removed from the public package:

- Old `README_v*.md` preview files.
- Old `RELEASE_NOTES_v*.md` preview files.
- Internal `V2_*_AUDIT.txt` audit logs.
- Development-only or garbled documentation files.
- Garbled Chinese batch filenames caused by earlier ZIP filename encoding issues.
- Legacy launcher shortcut.

Kept in the public package:

- Main source code.
- Environment setup and launcher scripts.
- Final README.
- Chinese and English user guides.
- Third-party license notes and license texts.
