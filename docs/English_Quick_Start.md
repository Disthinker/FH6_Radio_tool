# FH6 Radio Tool English Quick Start

## Switch UI Language

Open the tool and select:

```text
English
```

from the language selector near the top of the window.

## Basic Workflow

1. Select `RadioInfo_CN.xml`.
2. Select your custom music folder.
3. Select the target radio station.
4. Validate audio files.
5. Click `① Metadata CSV`.
6. Edit `output/track_metadata.csv`.
7. Use Fmod Bank Tools to Extract the original bank.
8. Click `② Import Extract`.
9. Select the WAV output directory generated by Fmod Bank Tools.
10. Click `③ Generate`.
11. In Fmod Bank Tools, set:

```text
Wav Output Directory = output/fmod_ready_wav
```

12. Rebuild the bank.
13. Replace the game XML and rebuilt bank.

## Final Output

```text
output/
  RadioInfo_CN.xml
  track_metadata.csv
  fmod_ready_wav/
```

## Notes

The tool does not include game files, bank files, XML files, or copyrighted music. Always back up your files before replacing anything.
