# FH6 Radio Tool 详细使用指南

> 面向普通用户的完整操作说明。建议先完整读一遍，再开始替换游戏电台音乐。

## 1. 工具能做什么

FH6 Radio Tool 用于辅助制作自定义游戏电台音乐。它负责：

- 读取并修改 `RadioInfo_CN.xml`；
- 校验用户导入的 WAV 音频；
- 生成歌曲显示名 / 艺人编辑表；
- 根据原 bank 的 Extract 结果自动建立映射；
- 将用户音乐平行替换到原 `sound_x.wav` 位置；
- 自动做基础音量匹配；
- 生成可直接用于 Fmod Bank Tools Rebuild 的 `fmod_ready_wav` 文件夹。

它不直接修改游戏文件，也不直接生成 bank。bank 仍然由 Fmod Bank Tools 手动重构。

## 2. 你需要准备什么

### 2.1 必备文件

你需要准备：

```text
1. 原游戏中文电台配置文件：RadioInfo_CN.xml
2. 你自己的音乐文件夹
3. 原游戏对应电台的 bank 文件
4. Fmod Bank Tools
```

### 2.2 音频格式建议

建议使用：

```text
WAV
48000 Hz
16-bit PCM
Stereo
```

如果音频不完全符合要求，工具会尽量规范化处理；但发布前仍建议你自己先整理好音源。

### 2.3 文件夹建议

建议把工具放在一个独立目录，例如：

```text
D:\FH6RadioTool\
```

不要放在系统目录、游戏安装目录、OneDrive 同步目录或需要管理员权限的目录。

## 3. 安装环境

双击：

```text
安装环境.bat
```

脚本会在工具目录下创建本地虚拟环境：

```text
.venv/
```

依赖会安装到 `.venv` 中，不会安装到全局 Python 环境。

安装脚本默认使用国内镜像：

```text
清华 PyPI 镜像
阿里云 PyPI 镜像
官方 PyPI
```

如果第一个镜像失败，会自动尝试下一个。

安装完成后，运行：

```text
启动工具.bat
```

## 4. 主流程概览

完整流程如下：

```text
1. 选择 RadioInfo_CN.xml
2. 选择音乐文件夹
3. 选择目标电台
4. 校验音频
5. 生成并编辑歌名表
6. 用 Fmod Bank Tools Extract 原 bank
7. 导入 Extract 的 wav 输出目录
8. 最终生成
9. 用 fmod_ready_wav 重构 bank
10. 替换游戏 XML 和新 bank
```

## 5. 第一步：选择 XML

点击工具中的 XML 选择按钮，选择：

```text
RadioInfo_CN.xml
```

如果你的游戏语言是中文，通常应修改中文对应的 XML。

工具成功读取后，会列出 XML 中可用的电台。

## 6. 第二步：选择音乐文件夹

选择你自己的音乐文件夹。

音乐数量不应超过目标电台原有曲目槽位数量。超出的文件会被丢弃或忽略，并在日志中提示。

建议音乐文件按你希望显示的顺序命名，例如：

```text
01_artist_title.wav
02_artist_title.wav
03_artist_title.wav
```

## 7. 第三步：选择目标电台并校验音频

选择你想替换的电台，然后点击：

```text
校验音频
```

工具会检查：

- 文件类型；
- 采样率；
- 声道；
- 位深；
- 可否读取。

如果需要规范化，工具会在内部流程中处理。

## 8. 第四步：生成并编辑歌名表

点击：

```text
① 歌名表
```

工具会生成：

```text
output/track_metadata.csv
```

用 Excel、WPS、VS Code 或记事本打开它。

你只需要编辑：

```text
display_name
artist
```

不要修改 `filename`，除非你很清楚自己在做什么。

示例：

```csv
filename,display_name,artist
01_song.wav,My Song,My Artist
02_song.wav,Another Song,Another Artist
```

保存 CSV 后，回到工具继续下一步。

## 9. 第五步：用 Fmod Bank Tools Extract 原 bank

打开 Fmod Bank Tools，对原游戏 bank 执行 Extract。

你需要 Extract 的是目标电台对应的 bank，例如：

```text
R4_Tracks_CU1.bank
```

Extract 后，Fmod Bank Tools 会生成类似结构：

```text
R4_Tracks_CU1.assets[0].txt
R4_Tracks_CU1.assets[0]/
  sound_0.wav
  sound_1.wav
  sound_2.wav
```

注意：请选择 Fmod Bank Tools 的 **wav 输出目录**，不是 build 目录，也不是 bank 目录。

## 10. 第六步：导入 Extract

点击：

```text
② 导入 Extract
```

选择上一步 Fmod Bank Tools 生成的 wav 输出目录。

工具会读取其中的：

- txt 行顺序；
- `sound_0.wav`、`sound_1.wav` 等原始 wav；
- 每个 wav 的采样点长度；
- 每个 wav 的采样率。

然后用原 XML 的：

```text
SampleLength
SampleRate
```

自动匹配原歌曲和 bank 中的 `sound_x.wav`。

这个过程对用户无感，正常情况下不需要手动修改映射表。

## 11. 第七步：最终生成

点击：

```text
③ 最终生成
```

工具会生成精简 output：

```text
output/
  RadioInfo_CN.xml
  track_metadata.csv
  fmod_ready_wav/
```

其中：

- `RadioInfo_CN.xml` 是最终游戏 XML；
- `track_metadata.csv` 是歌名表，保留方便你下次继续改；
- `fmod_ready_wav/` 是给 Fmod Bank Tools Rebuild 用的音乐文件夹。

`fmod_ready_wav/` 内部仍然保留原始结构：

```text
R4_Tracks_CU1.assets[0].txt
R4_Tracks_CU1.assets[0]/
  sound_0.wav
  sound_1.wav
```

但是这些 `sound_x.wav` 的内容已经被替换成你的自定义音乐，并且已经做了基础音量匹配。

## 12. 第八步：重构 bank

回到 Fmod Bank Tools。

将：

```text
Wav Output Directory
```

设置为：

```text
output/fmod_ready_wav
```

然后执行 Rebuild。

重构完成后，从 Fmod Bank Tools 的 build 输出目录中取得新的 bank 文件。

## 13. 第九步：替换游戏文件

将以下文件替换到游戏实际读取的位置：

```text
1. output/RadioInfo_CN.xml
2. Fmod Bank Tools build 出来的新 bank
```

注意：

- 必须替换正确电台对应的 bank；
- 文件名应与原 bank 保持一致；
- 不要把原 bank 又复制回去；
- 替换后建议完全退出并重启游戏。

## 14. 段落设置说明

右侧试听区域支持设置一些 Marker 字段。

常见字段含义：

```text
TrackStart：歌曲正式开始
TrackDrop：比赛中高潮 / 副歌 / Drop
TrackLoopStart / TrackLoopEnd：比赛中循环段
PostDrop：冲线或赛后高潮
PostRaceLoopStart / PostRaceLoopEnd：赛后循环段
DJSegment / DJStart：DJ 语音位置
StingerStart：短转场音效点
End：歌曲结束点
```

建议：

- 不确定的字段可以先不改；
- 循环段要选择节奏稳定的位置；
- `TrackLoopEnd` 应尽量能自然接回 `TrackLoopStart`；
- `End` 通常设置为歌曲最后一个有效采样点附近。

## 15. 音量匹配说明

工具会自动把用户音乐的活跃 RMS 音量对齐到原 extracted wav 的音量水平。

这不是专业母带处理，也不是完整 EBU R128 loudnorm，但足够避免大多数“某首歌突然太响 / 太小”的问题。

内部音量报告会放在：

```text
work/volume_match_report.csv
```

普通用户不需要查看。

## 16. output 与 work 的区别

正式输出：

```text
output/
  RadioInfo_CN.xml
  track_metadata.csv
  fmod_ready_wav/
```

内部调试文件：

```text
work/
```

`work/` 里可能包含：

- 映射表；
- Extract 模板；
- 音量报告；
- Fmod 辅助目录。

普通用户只需要看 `output/`。

## 17. 卸载与清理

如果不想保留环境，运行：

```text
卸载环境.bat
```

它会删除：

```text
.venv/
__pycache__/
*.pyc
```

并可选删除：

```text
output/
work/
backup/
```

如果 `.venv` 删除失败，通常是 Python 或工具窗口仍在运行。关闭工具，或在任务管理器中结束 `python.exe/pythonw.exe` 后再运行卸载脚本。

## 18. 常见问题

### Q1：歌名变了，但音乐没变

说明 XML 生效了，但 bank 没有正确替换。请确认你放回游戏目录的是 Rebuild 后的新 bank，不是原 bank。

### Q2：显示的歌名和播放的音乐错位

请确认你已经导入了正确电台的 Fmod Extract wav 目录，并重新点击 `③ 最终生成`。不要手动使用旧 assets.txt。

### Q3：导入 Extract 后提示无法匹配

可能原因：

- 导入了错误 bank 的 Extract 结果；
- 导入的不是 wav 输出目录；
- 原 XML 与 bank 不对应；
- Extract 出来的 wav 采样长度与 XML 中 `SampleLength` 不一致。

### Q4：音乐太响或太小

v3.5 已自动做基础音量匹配。如果仍不满意，可以先在音频编辑软件中处理源音乐，再重新生成。

### Q5：可以删除 work 吗？

可以。`work/` 是内部文件目录。正式使用时只需要 `output/` 中的三个产物。但如果你要排查问题，建议先保留 `work/`。
