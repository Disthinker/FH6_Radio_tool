# FH6 Radio Tool 详细使用指南（B站友好版）

> 这是给普通玩家看的说明书。  
> 你不需要理解什么 `bank_index`、`slot_index`、`sound_x.wav`，工具会在后台帮你处理。  
> 你只要按流程来，别跳步骤，基本就不会“歌名是 A，播放是 B”。

## 1. 这个工具到底干嘛

你想把游戏电台里的歌换成自己的歌单。

但直接替换会遇到几个经典问题：

```text
歌名改了，音乐没变
音乐变了，歌名错位
sound_0.wav 到底是哪首歌，鬼知道
音量一首大一首小，耳机当场起飞
```

FH6 Radio Tool 主要解决这些问题：

- 修改 `RadioInfo_CN.xml`；
- 生成歌名 / 艺人编辑表；
- 自动识别原 bank 里的 `sound_0.wav` 对应 XML 里的哪首歌；
- 把你的音乐塞回正确位置；
- 自动做基础音量匹配；
- 生成给 Fmod Bank Tools 重构用的 `fmod_ready_wav` 文件夹。

---

## 2. 你需要准备什么

你需要：

```text
1. 本工具
2. Python 环境，或者直接用本工具的 安装环境.bat
3. Fmod Bank Tools
4. 原游戏 RadioInfo_CN.xml
5. 原游戏对应电台的 bank 文件
6. 你自己的 WAV 音乐文件夹
```

建议音乐格式：

```text
WAV
48000 Hz
16-bit PCM
Stereo
```

不符合时工具会尽量处理，但音源越规整，出问题概率越低。

---

## 3. 安装环境

双击：

```text
安装环境.bat
```

脚本会在工具目录下创建：

```text
.venv/
```

这是本工具自己的虚拟环境，不会把依赖乱装到你电脑全局 Python 里。

安装脚本默认走国内镜像：

```text
清华镜像
阿里云镜像
官方 PyPI
```

所以一般不需要你会 pip 代理。  
如果全都失败，那大概率是网络、Python 安装或安全软件拦截问题。

安装完成后，双击：

```text
启动工具.bat
```

---

## 4. 总流程

建议照着这个顺序走：

```text
1. 选择 XML
2. 选择音乐文件夹
3. 选择电台
4. 校验音频
5. 点 ① 歌名表
6. 编辑 output/track_metadata.csv
7. 用 Fmod Bank Tools Extract 原 bank
8. 点 ② 导入 Extract
9. 点 ③ 最终生成
10. 用 output/fmod_ready_wav 在 Fmod Bank Tools 里 Rebuild
11. 替换游戏里的 XML 和新 bank
```

不要跳步骤。  
跳步骤的后果通常是：你开始怀疑人生，工具开始沉默，游戏继续放原曲。

---

## 5. 选择 XML

在工具里选择：

```text
RadioInfo_CN.xml
```

如果你玩的是中文语言，通常就改这个中文 XML。

选完后，工具会读取里面的电台信息。

---

## 6. 选择音乐文件夹

选择你准备好的音乐文件夹。

建议命名：

```text
01_歌名.wav
02_歌名.wav
03_歌名.wav
```

数量不要超过原电台曲目槽位数量。  
如果多了，工具会丢弃超出的部分或提示。

---

## 7. 校验音频

点击：

```text
校验音频
```

工具会检查音频能不能正常用。

如果某些音频格式不合适，工具会尝试规范化。  
但最好你自己一开始就准备规范 WAV，减少翻车概率。

---

## 8. 生成歌名表

点击：

```text
① 歌名表
```

工具会生成：

```text
output/track_metadata.csv
```

打开它，主要改两列：

```text
display_name
artist
```

不要乱改 `filename`。

示例：

```csv
filename,display_name,artist
01_song.wav,我的歌名,我的艺人
02_song.wav,下一首歌,另一个艺人
```

保存后回到工具。

---

## 9. 下载并使用 Fmod Bank Tools

### 9.1 下载

打开仓库：

```text
https://github.com/Wouldubeinta/Fmod-Bank-Tools.git
```

通常有两种方式：

```text
1. 去 Releases 下载别人打包好的版本
2. 或者下载源码自己编译
```

普通用户优先找 Releases。  
如果没有现成包，那就需要根据仓库说明自行编译，这一步会稍微硬核一点。

### 9.2 Extract 原 bank

打开 Fmod Bank Tools。

把你要替换的原 bank 放到 Fmod Bank Tools 的 bank 输入目录，然后执行：

```text
Extract
```

Extract 后会得到类似：

```text
R4_Tracks_CU1.assets[0].txt
R4_Tracks_CU1.assets[0]/
  sound_0.wav
  sound_1.wav
  sound_2.wav
```

注意：  
`sound_0.wav` 这种名字没有歌名信息，完全正常，不是你操作错了。

### 9.3 回到本工具导入 Extract

在 FH6 Radio Tool 里点击：

```text
② 导入 Extract
```

选择 Fmod Bank Tools 的 wav 输出目录。

也就是包含：

```text
*.txt
对应的 sound_x.wav 文件夹
```

的那个目录。

不要选：

```text
bank 目录
build 目录
fsb 目录
某个单独 sound_x.wav 子文件夹
```

选错目录会导致匹配失败。

---

## 10. 最终生成

点击：

```text
③ 最终生成
```

工具会生成：

```text
output/
  RadioInfo_CN.xml
  track_metadata.csv
  fmod_ready_wav/
```

其中最重要的是：

```text
output/fmod_ready_wav/
```

这里面的结构看起来仍然像原来的 Extract：

```text
R4_Tracks_CU1.assets[0].txt
R4_Tracks_CU1.assets[0]/
  sound_0.wav
  sound_1.wav
```

但里面的 `sound_x.wav` 内容已经换成你的音乐，并做了基础音量匹配。

你不需要手动知道哪首歌对应哪个 `sound_x.wav`。  
工具已经通过 `SampleLength / SampleRate` 做了映射。

---

## 11. Rebuild bank

回到 Fmod Bank Tools。

设置：

```text
Wav Output Directory = output/fmod_ready_wav
```

然后执行：

```text
Rebuild
```

重构完成后，从 Fmod Bank Tools 的 build 输出目录拿到新 bank。

---

## 12. 替换游戏文件

把下面两个东西放回游戏实际读取的位置：

```text
1. output/RadioInfo_CN.xml
2. Fmod Bank Tools build 出来的新 bank
```

注意：

- bank 文件名要和原来的保持一致；
- 不要把原 bank 又复制回去了；
- 如果用了 mod 管理器，确认优先级别被覆盖；
- 替换后最好完全重启游戏。

---

## 13. 段落字段怎么看

右侧试听区域可以设置一些段落点。

速记版：

```text
TrackStart：歌曲正式开始
TrackDrop：比赛中高潮 / 副歌 / Drop
TrackLoopStart / TrackLoopEnd：比赛中循环段
PostDrop：冲线或赛后高潮
PostRaceLoopStart / PostRaceLoopEnd：赛后循环段
DJSegment / DJStart：DJ 语音位置
StingerStart：短转场音效点
End：歌曲结束点
```

建议：

- 不懂就先别改；
- 循环点不要乱填；
- 循环段最好听起来能自然接回去；
- `End` 通常放在歌曲最后一个有效声音附近。

---

## 14. 音量匹配

工具会自动做基础音量匹配。

原理很简单：

```text
读取原 sound_x.wav 的活跃音量
读取你的音乐的活跃音量
把你的音乐调到接近原音量
```

这不是专业母带，不会让所有歌听起来像同一张专辑。  
但至少能减少“上一首蚊子叫，下一首核爆”的情况。

---

## 15. output 和 work 是什么

最终你需要用的是：

```text
output/
```

里面只有：

```text
RadioInfo_CN.xml
track_metadata.csv
fmod_ready_wav/
```

`work/` 是内部文件和调试文件。  
普通用户不用管。

---

## 16. 卸载

双击：

```text
卸载环境.bat
```

可以删除：

```text
.venv/
Python 缓存
```

并可选删除：

```text
output/
work/
backup/
```

如果 `.venv` 删不掉，说明工具或 Python 还在运行。  
关掉窗口，或者任务管理器结束 `python.exe / pythonw.exe` 后再试。

## 17. 常见问题

### Q：歌名变了，但音乐没变

你替换了 XML，但 bank 没换成功。  
检查你放回游戏的是不是 Rebuild 后的新 bank。

### Q：音乐变了，但歌名和实际播放对不上

重新确认你导入的是对应电台 bank 的 Extract wav 输出目录。  
不要导入错 bank，也不要导入 build 目录。

### Q：Extract 出来全是 sound_0.wav，正常吗？

正常。  
这就是本工具存在的意义之一。

### Q：可以只用 output/fmod_ready_wav 吗？

对。  
Rebuild 时把 Fmod Bank Tools 的 `Wav Output Directory` 指向它。

### Q：我能不能把工具和音乐一起打包分享？

工具可以分享。  
但不要分享游戏原始 bank、游戏原始 XML、商业音乐或任何你没有版权的内容。

## 英文备用批处理

如果你的 Windows 环境里中文批处理显示乱码，可以改用英文文件名：

```text
setup_env.bat      等同于 安装环境.bat
run_tool.bat       等同于 启动工具.bat
cleanup_env.bat    等同于 卸载环境.bat
```

功能完全一样，只是文件名更适合非中文系统或编码比较玄学的环境。
