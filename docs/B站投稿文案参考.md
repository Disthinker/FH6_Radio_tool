
简介参考：

```text
做了一个地平线电台音乐替换辅助工具，主要解决几个痛点：

1. 自动改 RadioInfo_CN.xml
2. 可以编辑游戏内显示歌名和 artist
3. 自动匹配 Fmod Extract 出来的 sound_0.wav / sound_1.wav
4. 自动平行替换音频，减少歌名和实际播放错位
5. 自动做基础音量匹配
6. 最终只需要把 output/fmod_ready_wav 丢给 Fmod Bank Tools Rebuild

感谢参考教程：
https://www.bilibili.com/opus/748254891671027745?from=search&spm_id_from=333.337.0.0

感谢 Fmod Bank Tools 及作者 Wouldubeinta：
https://github.com/Wouldubeinta/Fmod-Bank-Tools.git

注意：
本工具不提供游戏文件、不提供 bank、不提供音乐资源。
请自行准备合法音源，折腾前记得备份。
```
